09 · Interface

Using the mark

  • Clear space around the mark is one arm (⅛ of the tile) on every side.
  • Minimum size is 16 px for the icon and 48 px wide for the wordmark.
  • Blue is only ever the fold: the folded corner, the dot on the i, a primary action. Never a background wash, never a gradient.
  • Don't rotate, outline, add shadows to, recolor or redraw the F. Use the files in brand/.

Downloads: brand/ on GitHub (SVG mark, wordmark, lockups and document icons). Released under the project's MIT license; the name and mark identify the Folio project.
