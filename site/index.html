Every file you edit,
in one native Mac app.

Folio opens and edits PDFs, documents, spreadsheets, images, code and media. It runs entirely on your Mac, and its source is open for anyone to read.

Six editors, one app

Each kind of file gets an editor built on the engine macOS already uses for it, so files open the way you expect and save back to the format they came in.

  • PDF

    Annotate, sign and fill in forms. Redaction removes the text underneath instead of drawing a box over it. Recognise text in scans with OCR, and rotate, reorder, split or merge pages.

    PDF

  • Documents

    Write and format Word, RTF and OpenDocument files with the Cocoa text system, including Writing Tools on Macs that support them.

    DOCX · DOC · RTF · ODT · HTML

  • Spreadsheets

    Edit cells and formulas, then save back to Excel, CSV or OpenDocument without converting through another app.

    XLSX · CSV · TSV · ODS

  • Images

    Adjust light and color, crop and rotate, remove a background in one step, and select text inside a photo with Live Text.

    PNG · JPEG · HEIC · TIFF · GIF · WebP

  • Text and code

    Syntax highlighting for source files, and a side-by-side preview for Markdown that updates as you write.

    TXT · MD · JSON · YAML · source files

  • Audio and video

    Play and trim without re-encoding, so cuts are lossless, then export to another format when you need one.

    MP4 · MOV · MP3 · M4A · WAV

Feels like a Mac app, because it is one

Folio is written in Swift with SwiftUI and AppKit. Menus, shortcuts, Undo and Find work the way they do everywhere else on your Mac.

  • Autosave and Versions

    Changes save about a second after you stop. Earlier versions are in File › Revert To.

  • Opens in under a second

    A design goal, measured on every change with make launch-time.

  • Finder Quick Actions

    Combine PDFs or convert images from the Finder without opening a window.

  • Services

    Folio’s tools appear in the Services menu of the apps you already use.

  • Continuity Camera

    Insert a photo or a document scan straight from your iPhone.

  • Dark mode

    Every screen is designed and checked in both light and dark appearance.

  • Tabs

    Merge documents into one window with tabs, or pull them apart again.

  • iCloud Drive

    Open and save files in iCloud Drive like any other folder.

Private by design

Folio has no servers to send your files to. OCR, background removal and Live Text use frameworks built into macOS and run on your Mac.

  • No account

    There is nothing to sign up for or sign in to.

  • No network requests

    No analytics, no telemetry, no cloud processing.

  • Files stay on your Mac

    Your documents are read and written locally, and nowhere else.

Build from source 
$ git clone https://github.com/AryanM24/folio
$ cd folio
$ make run

make run builds build/Folio.app and opens it. make test runs every test suite.
