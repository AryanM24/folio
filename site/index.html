1

Convert anything it opens, and say exactly what changed

Pick a format and how hard to squeeze: lossless, balanced or small. Folio takes the fastest route macOS has, reports the size before and after, and never touches the original.

  • Lossless means checked

    Folio decodes what it wrote and compares it pixel by pixel or sample by sample. When a format can't be lossless, it says so instead of quietly degrading.

  • Never bigger

    A compressed copy that isn't smaller is thrown away, and the original stays as it was.

  • Never overwrites

    Results land next to the original as new files. Nothing is replaced or deleted.

    The same conversions are in Finder: select files, then Quick Actions › Convert with Folio. Or drop files on Folio in the menu bar.

    4

    Six editors, one app

    Each kind of file gets an editor built on the engine macOS already uses for it, so files open the way you expect and save back to the format they came in.

    1. PDF

      Annotate, sign and fill forms. Redaction removes the text underneath. OCR for scans, and pages you can rotate, reorder, split or merge.

      PDF

    2. Documents

      Write and format with the Cocoa text system, including Writing Tools on Macs that support them.

      DOCX · RTF · ODT · HTML

    3. Spreadsheets

      Cells and formulas that save back to Excel, CSV or OpenDocument.

      XLSX · CSV · TSV · ODS

    4. Images

      Light and color, crop and rotate, background removal in one step, and Live Text.

      HEIC · PNG · JPEG · AVIF · TIFF

    5. Text and code

      Syntax highlighting in 25 languages, and a Markdown preview that updates as you type.

      MD · JSON · YAML · source

    6. Audio and video

      Play and trim without re-encoding, so cuts are lossless.

      MP4 · MOV · M4A · WAV · FLAC
