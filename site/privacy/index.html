Privacy

Effective 27 November 2026

Folio doesn't collect anything. This page explains what that means for the app, the folio command, and this website.

The Folio app

  • No data leaves your Mac. Folio makes no network requests: no analytics, telemetry, crash reports, accounts or update checks.
  • Your files stay where they are. Folio reads and writes only the files you open, save or convert. Conversions write new files next to the originals and never change or delete them.
  • Converting web pages stays offline. When Folio opens HTML or Markdown, it removes links to remote images, styles and scripts and blocks every network load, so a document can't make your Mac contact a server.
  • Local data. Signatures you draw and your settings are stored on your Mac, in ~/Library/Application Support/Folio/ and Folio's preferences. Deleting the app and that folder removes them.
  • Spotlight and Finder tags. Recent and Favorites use your Mac's own Spotlight index and Finder tags. Nothing is copied anywhere.

The folio command and AI agents

  • The folio command and its MCP server run on your Mac and make no network requests either.
  • When you connect an AI client (Claude Code, Claude Desktop, Cursor, Codex or another), that client decides what to send to its own servers. If you ask it to read a file through Folio, the text it reads may go to the client's provider under that provider's privacy policy. Folio has no part in that and receives nothing.
  • Folio only reads and writes inside folders you allow, and always refuses sensitive places such as ~/Library and ~/.ssh. See the security model.
  • Settings › Agents changes another app's configuration only after you confirm, and keeps a backup.

This website

  • No cookies, no analytics, no tracking scripts, no forms.
  • Your theme choice is kept in your browser's local storage and never sent anywhere.
  • The site is hosted by Vercel, which processes standard request logs (such as IP address and browser) to deliver and protect the site. See Vercel's privacy policy.
  • Downloads and source code are served by GitHub under GitHub's privacy statement.

Changes and contact

If this ever changes, this page and the changelog will say so before a release ships it. Questions go to GitHub issues; security reports go through private vulnerability reporting.
